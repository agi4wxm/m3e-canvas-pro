# 组件盘点

这份清单记录 `源码/` 下每个来源的每个组件，现在由哪个组件承担。`parts/coverage.test.ts` 会检查表里写的组件都真实存在，所以它不会和代码脱节。

所有组件都按同一种方式重新实现（见[组件规范](组件规范.md)），没有搬外部库的代码和样式。这里的“对应”指用途相同：iOS、Miuix 等平台的组件都按 M3E 外观绘制，不还原原平台的样子。
