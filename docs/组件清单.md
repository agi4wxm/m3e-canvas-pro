## 容器

能放组件的有 8 个：`container`、`stack`、`grid-view`、`dock`、`supporting-pane`、`resizable`、`window`、`custom`。它们按位置判断包含关系，和画板带组件的方式一样：

- 组件完全落在容器内、并且画在容器上层，就算在容器里；拖出来就不算了。没有单独的子项列表需要同步。
- 拖动或用方向键移动容器时，里面的内容一起移动；容器里的容器也一样。锁定的分组不跟着动。
- 容器放到已有组件上时会退到它们后面，不会盖住它们。
- 提示词按同样的规则描述嵌套。

## 没有验证的

- **AI 生成：** 没有 API 密钥，没有实际让模型生成过。只验证了给 AI 的说明和组件定义同步，以及校验规则。
- **文件上传的拖放、可排序列表的拖动、屏幕取色：** 只验证了绘制，没有模拟拖放。
- **视频、网页、音频的真实地址：** 只验证了没有地址时的占位，没有加载真实媒体。
