## 容器

能放组件的有 8 个：`container`、`stack`、`grid-view`、`dock`、`supporting-pane`、`resizable`、`window`、`custom`。

**没开自动布局时**按位置判断包含关系，和画板带组件的方式一样：

- 组件完全落在容器内、并且画在容器上层，就算在容器里；拖出来就不算了。
- 拖动、用方向键移动或复制容器时，里面的内容一起走；容器里的容器也一样。锁定的分组不跟着动。
- 容器放到已有组件上时会退到它们后面，不会盖住它们。

**开了自动布局时**（`container`、`dock`、`supporting-pane`、`window`、`custom` 可选横排、竖排、网格，`grid-view` 固定为网格）：

- 组件拖进去就排好，拖动可以调整顺序，拖到容器外就离开。内容超出容器也不会掉出来。
- 可设置间距、内边距、对齐、分布、换行、列数、宽高随内容；里面的组件可以占满剩余空间。容器可以嵌套。
- 多选后点“添加自动布局”，会按现在的排列方向放进一个新容器。
- `dock` 每个标签放自己的内容。

## 没有验证的

- **AI 生成：** 没有 API 密钥，没有实际让模型生成过。只验证了给 AI 的说明和组件定义同步，以及校验规则。
- **文件上传的拖放、可排序列表的拖动、屏幕取色：** 只验证了绘制，没有模拟拖放。
- **视频、网页、音频的真实地址：** 只验证了没有地址时的占位，没有加载真实媒体。
- **二维码的真实扫描：** 没有用手机或扫码器扫过，只验证了按标准读回。深色主题下是浅色模块配深色底，部分扫码器可能读不出。
- **看板的拖动：** 用合成的拖放事件验证过，没有用真实鼠标拖过；点选卡片后的左右移动按钮实际操作过。
- **应用组件的深色主题和手机触屏：** 没有逐个看过。
- **模态侧边栏和底部菜单在画布上的样子：** 画布上模态侧边栏展开后，选中框仍是收起时的宽度；底部的菜单在画布上仍向下画，只有预览和导出的项目才会往上展开。
- **圆角滑块的起始数字：** 主题不是默认比例时，滑块一开始显示的仍是标准比例下的数值；拖动后以滑块为准。
- **真实触屏：** 手机宽度的布局用鼠标验证过，没有用真实手指操作过。
