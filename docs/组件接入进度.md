# 组件清单

日期：2026 年 11 月 4 日。

这是一个重构后的独立项目。组件的思路和部分代码来自 m3e-canvas 的各个分支（见 `NOTICE`），但项目运行时不依赖它们，也不兼容它们的文件格式：只打开自己保存的文件。

## 容器

能放组件的有 6 个：`layout/container`、`stack`、`grid-view`、`dock`、`supporting-pane` 和 `resizable`，都写了 `holds: true`。它们按位置判断包含关系，和画板带组件的方式一样：

- 组件完全落在容器内、并且画在容器上层，就算在容器里；拖出来就不算了。没有单独的子项列表需要同步。
- 拖动或用方向键移动容器时，里面的内容一起移动；容器里的容器也一样。锁定的分组不跟着动。
- 容器放到已有组件上时会退到它们后面，不会盖住它们。
- 提示词本来就按这个规则判断嵌套，生成的描述是“layered inside”。

容器里的组件要手动摆放，容器不会自动排版。所以 `layout/grid-view` 不会把内容排进格子，`layout/dock` 切换标签不会切换内容。`resizable` 的分隔条在预览里能拖动，但放在上面的组件不会跟着变。

## 实测

| 检查项 | 结果 |
| --- | --- |
| 类型检查、构建 | 通过 |
| 单元测试 | 1055 个通过 |
| 浏览器实测（生产构建、无头 Edge、真实鼠标） | 11 组用例，控制台 0 个错误 |
| 面板 | 12 个分区顺序正确；默认显示 124 个组件，展开 Ant Design 后共 136 个；搜不到已删除的组件 |
| 游戏组件 | 6 种抽奖都实际点击，转动中和结束后的状态正确，固定结果和设定一致；背包、任务、奖励、签到、倒计时都实际操作过 |
| Ant Design | 下拉在组件旁边展开，页签、菜单、分页、表格都实际操作过 |
| 容器（真实鼠标） | 拖动容器时里面的跟着动、外面的不动；撤销一次全部回到原位；拖出去后不再跟随，拖进来后开始跟随；方向键同样带上；容器放到组件上时退到后面 |
| 打开文件 | 自己保存的文件能打开；Miuix、SwiftUI 格式、其他信封和含未知 Kind 的文件都被拒绝，画布不变 |
