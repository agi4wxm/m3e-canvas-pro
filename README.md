# M3E Canvas Pro

在浏览器里用现成组件拖拽搭出可交互的应用原型，再导出成能运行的 React 项目或给 AI 的提示词。基于 [m3e-canvas](https://github.com/lnkiai/m3e-canvas) 和 [shadcn M3E](https://github.com/Crysta1221/shadcn-m3e)，把各分支和组件库的组件全部按同一种方式重新实现。这是一个重构后的独立项目，只打开自己保存的文件，不兼容其他分支的文件格式。

## 能做什么

| 方面 | 功能 |
| --- | --- |
| 组件 | 211 个组件，填充色、文字色、圆角、边框、阴影、透明度、毛玻璃、旋转、渐变、字体可改（少数没有表面的除外） |
| 风格 | 25 套对照真实产品的风格：微信、iOS、抖音、Windows、VS Code、原神、黑神话、赛博朋克 2077 等，每套都是一份规范：配色和字体、控件形状、边距和导航位置一键换掉，之后手动修改、AI 和自动排版都被约束在规范内。组件和风格解耦，同一个组件在不同风格下呈现不同，见 [风格清单](docs/风格清单.md) |
| 模板 | 28 个屏幕和流程模板，从登录、购物到后台，都用自动布局搭建 |
| 排版 | 自动布局（横排、竖排、网格、间距、内边距、对齐、分布、换行、随内容、占满剩余，可嵌套），对齐线，4dp 网格，多选对齐和分布，按数字设位置，一键整理 |
| 屏幕 | 手机、平板、桌面和自定义尺寸，长屏滚动，状态栏和安全区，可垫一张设计稿描图，同一屏幕可建多个尺寸的变体 |
| 复用 | 可复用组件（一处定义，多处实例，实例可覆盖文字、图标、图片） |
| 数据 | 数据集合驱动的重复列表，点一行把这行数据带到详情页 |
| 交互 | 跳转、返回、外链；显示隐藏、开关弹层、设变量、改属性、提示条；按变量或输入内容走不同分支；输入框写入变量，属性可绑定变量；Dock 按标签切换内容 |
| 图层 | 重命名、搜索、隐藏、锁定、调整层级 |
| 输出 | 下载可运行的完整项目（zip）、复制代码、给 AI 的提示词、分享链接、导出屏幕图片 |

## 启动

需要 [Node](https://nodejs.org/) 22 以上和 [bun](https://bun.sh/) 1.4。

```bash
bun install
```

```bash
bun run dev
```

然后打开 http://localhost:3000。

| 命令 | 作用 |
| --- | --- |
| `bun run build` | 生产构建，输出到 `dist/` |
| `bun run preview` | 预览生产构建 |
| `bun run typecheck` | 类型检查 |
| `bun run test` | 运行测试 |
| `bun run gen:parts` | 重新生成组件索引 |
| `bun run gen:agent` | 把组件清单写进 `public/agent.md` |
| `bun run check:export <空文件夹>` | 生成项目，真的安装、构建，再用无头 Edge 点一遍 |

在 Windows 上，项目路径要尽量短。依赖目录层级很深，放在超长路径下安装可能失败。

## 目录

```text
src/           应用入口和编辑器
components/    编辑器界面
components/m3e/  Material 3 Expressive 组件库
lib/           文档模型、提示词和代码生成
lib/m3e/       组件库的工具代码
hooks/         组件库的 Hook
styles/        组件库的样式和设计令牌
parts/         组件注册表和绘制
parts/defs/    组件定义
parts/widgets/ 自带组件
parts/templates/ 屏幕和流程模板
public/        静态资源
scripts/       生成脚本
docs/          组件规范、清单和盘点
```
